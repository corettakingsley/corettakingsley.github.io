# Cloud Engineering Portfolio

A responsive, dark-themed personal portfolio built with HTML, CSS and vanilla JavaScript. Designed for deployment with GitHub Pages.

## Run locally

1. Download or clone this repository.
2. Open `index.html` in a browser.

For a local development server, you can use the VS Code Live Server extension.

## Publish with GitHub Pages

This repository is intended to use the GitHub Pages user-site address:

`https://corettakingsley.github.io/`

1. Push the project files to the `main` branch.
2. Open **Settings → Pages** in the repository.
3. Under **Build and deployment**, select **Deploy from a branch**.
4. Select branch `main` and folder `/ (root)`.
5. Save and wait for the deployment to finish.

## Before publishing

- Replace the LinkedIn placeholder with your actual profile URL.
- Add a professional email address if you want it public.
- Verify the education status and certification details.
- Add public project repository links, architecture diagrams and screenshots.
- Remove or revise any project description that you cannot publicly disclose.
- Never commit passwords, API keys, tokens, connection strings or confidential company files.
